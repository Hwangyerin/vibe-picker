# VibePicker

> 사진 한 장의 분위기(vibe)를 색으로 꺼내, 그 색으로 만든 화면을 바로 보고 AI에게 넘길 프롬프트까지 복사하는 웹앱

> 현재 기획 단계입니다. 작업이 진행될 때마다 이 README를 채워 갑니다.

---

## 1. 제작한 것 소개

### 왜 만들었나

첫인상은 색이 정합니다. 사람은 처음 본 대상을 90초 안에 판단하고 그 판단의 62~90%가 색에서 나오며([Singh, 2006](https://www.researchgate.net/publication/235320162_Impact_of_color_on_marketing)), 웹페이지의 첫인상은 0.05초 만에 정해집니다([Lindgaard 외, 2006](https://www.tandfonline.com/doi/abs/10.1080/01449290500330448)).

하지만 디자인이 어려운 사람은 색을 어디서 가져올지부터 막막하고, 골라도 어디에 써야 할지 모릅니다. AI에게 화면을 맡겨도 색을 정해주지 않으면 결과물은 늘 어디서 본 듯한 AI 티를 벗어나지 못합니다.

VibePicker는 누구나 보는 순간 분위기를 느끼는 사진에서 출발합니다.

### 주요 기능

| 기능 | 설명 |
| --- | --- |
| 색 뽑기 | 사진을 올리면 대표색 5개를 컬러칩(HEX, RGB)으로 보여주고, 클릭하면 복사 |
| 다시 뽑기 | 같은 사진에서 다른 5색 조합을 새로 뽑기 |
| 스포이드 · my pick | 사진에서 원하는 곳을 찍어 칩 색을 바꾸고, 고른 칩은 다시 뽑기에도 고정 |
| 예시 화면 | 뽑은 색을 발표 슬라이드, 웹사이트, 앱 화면 목업에 바로 입혀 보기 |
| 랜덤 섞기 · 대비 슬라이더 | 색 역할을 섞어 보고, 읽기 어려운 조합은 경고와 함께 슬라이더로 고치기 |
| 라이트 · 다크 | 팔레트에 어울리는 라이트·다크 배경으로 전환 |
| AI 프롬프트 복사 | 역할별 색과 사용 규칙을 AI 에이전트에게 넘길 프롬프트로 복사 |
| 서랍 | 마음에 드는 팔레트를 저장하고 다시 불러와 조절 |

## 로컬에서 실행하기

자바스크립트를 기능별 모듈로 나눠서, `index.html`을 더블클릭하면 동작하지 않습니다. 로컬 서버로 열어 주세요.

1. VS Code에서 확장 프로그램 **Live Server**를 설치합니다.
2. `index.html`을 연 상태에서 오른쪽 아래 **Go Live**를 누릅니다.
3. 브라우저에 `http://127.0.0.1:5500`으로 열리고, 파일을 저장할 때마다 자동으로 새로고침됩니다.
