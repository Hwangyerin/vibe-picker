# browser-qa 기록

`browser-qa` 스킬로 실제 브라우저에서 확인하다가 발견한 문제와 처리 결과. (README "스킬" 항목의 사용 사례)

| 날짜 | 단계 | 발견한 문제 | 원인 | 처리 |
| --- | --- | --- | --- | --- |
| 10-31 | 7-6 | Chrome에서 `localhost:8000`이 열리지 않음 | 이 환경의 Chrome이 localhost 연결에 실패 | `127.0.0.1`로 접속, 스킬에 반영 |
| 10-31 | 8 | `--accent-soft`가 파랑이 아니라 분홍으로 보임 | `color-mix(in oklch)`가 흰색(색조 0)과 섞으며 색조를 돌려 버림 | 모든 color-mix를 `in oklab`으로 |
| 10-31 | 8 | 아이콘이 하나도 안 보임 | 스프라이트 주석에 `--`가 들어가 SVG(XML)가 깨짐 | 주석 수정, XML 파싱으로 검증 |
| 10-31 | 8 | 아이콘이 300px 검은 덩어리로 보임 | 브라우저가 고치기 전 v1 `base.css`를 캐시에서 계속 씀 | 캐시를 끈 개발 서버 `tools/serve.py` 추가, 스킬에 반영 |
| 10-31 | 8 | 세그먼트 글자가 선택 표시보다 위로 치우침 | 부모 격자가 세그먼트를 44px로 늘림 | `.segmented`에 `align-self: start`, `align-items: center` |
| 10-31 | 8 | 390px에서 가로 스크롤 (426px) | 격자 열이 내용 최소 폭만큼 늘어남 | 견본 페이지 격자에 `minmax(0, 1fr)` |
| 10-31 | 8 | 창을 390px로 줄일 수 없음 | Chrome 창 최소 폭 약 500px | 정해진 너비 iframe으로 보는 `tools/viewport.html` 추가 |
