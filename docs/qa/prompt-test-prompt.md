# Planit 브랜드로 모바일 웹 화면 만들기

아래 브랜드 규칙을 지켜 가로 390px 기준 모바일 웹 화면을 만들어 주세요.
만들 화면: (여기에 적어 주세요. 예: 로그인 화면, 설정 화면, 3장짜리 중간 발표)

## 1. 색
라이트 모드가 기본입니다. 다크 모드는 prefers-color-scheme: dark일 때 다크 열의 값으로 바꿉니다.

| 역할 | 라이트 | 다크 | 쓰는 곳 |
| --- | --- | --- | --- |
| 바탕 | #F7F7F8 | #16181D | 페이지 배경 |
| 면 | #FEFEFE | #202328 | 카드, 입력창, 탭바 |
| 글자 | #0F1319 | #E0E3EC | 본문, 제목 |
| 보조 글자 | #616367 | #A2A5A9 | 설명, 날짜, 자리 표시 글자 |
| 경계선 | #D7DADD | #333538 | 카드·입력창 테두리 (1px) |
| Primary | #557096 | #557096 | 주요 버튼 하나, 선택된 탭, 오늘 날짜 — 화면마다 한 가지 행동에만 |
| Primary 위 글자 | #FFFFFF | #FFFFFF | Primary 면 위의 글자·아이콘 |
| Secondary | #E1ECFB | #293442 | 옅은 강조 면: 진행률 카드, 아이콘 바탕, 보조 버튼 |
| Secondary 위 글자 | #2A4366 | #BFDAFF | Secondary 면 위의 글자 |
| Point | #6A9BDF | #6A9BDF | 작은 표시: 점, 태그 바탕(옅게) |
| Sub | #B1BDD5 | #B1BDD5 | 보조 태그, 아바타 |

회색 5단계 (라이트): #F4F5F7, #CED1D6, #8F9296, #505356, #191B1E

## 2. 서체
- 제목: Gothic A1, 굵기 700 — https://fonts.googleapis.com/css2?display=swap&family=Gothic+A1:wght@400;500;700
- 본문: Pretendard, 굵기 400(본문) / 600(강조) — https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css
- 숫자·시간은 font-variant-numeric: tabular-nums

## 3. 아이콘
- Lucide 세트만 쓰고 선 굵기는 1.75 (보통)
- 이모지를 아이콘 대신 쓰지 않습니다

## 4. 모양
- 카드·패널 둥글기: 12px
- 버튼·입력창·태그 둥글기: 12px
- 터치 대상은 최소 44px
- 제목 28~32px, 본문 15~16px, 보조 글자 12~13px
- 그림자는 떠 있는 요소(플로팅 버튼, 시트)에만 쓰고, 나머지는 1px 경계선으로 나눕니다

## 5. 지켜야 할 것
1. 위 표에 없는 색을 새로 만들지 않습니다 (같은 색의 투명도 조절은 괜찮습니다)
2. Primary는 화면마다 주요 행동 하나에만 씁니다. 모든 버튼·링크·아이콘을 Primary로 칠하지 않습니다
3. 본문 글자와 바탕의 대비는 4.5:1 이상입니다 (지금 라이트 17.4:1)
4. 그라데이션 배경, 유리(blur) 효과, 보라·파랑 기본 색을 쓰지 않습니다
5. "손쉽게", "한눈에" 같은 상투적인 문구 대신 구체적인 문장을 씁니다
